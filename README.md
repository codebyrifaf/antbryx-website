## About AntBryx

**AntBryx is a software startup founded and developed by Rifaf.**

The company focuses on building software products and delivering modern technology solutions for businesses and users.

This repository contains the source code for the official AntBryx website. The website serves as the company's primary digital presence, presenting the AntBryx brand, capabilities, products, services, and technology-focused approach.

This is a real-world startup project rather than a tutorial or template project.

## Architecture

The project follows a modern Next.js application architecture with a modular and reusable component structure.

```text
antbryx-website/
│
├── app/
│   └── Next.js application routes and pages
│
├── components/
│   └── Reusable UI and application components
│
├── hooks/
│   └── Custom React hooks
│
├── lib/
│   └── Utility functions and shared application logic
│
├── public/
│   └── Static assets and public resources
│
├── styles/
│   └── Global styles
│
├── components.json
├── next.config.mjs
├── package.json
├── package-lock.json
├── pnpm-lock.yaml
├── postcss.config.mjs
├── tsconfig.json
└── README.md
```

The architecture separates application routes, reusable components, hooks, utilities, static assets, and styling to keep the project maintainable and scalable.

## Getting Started

### Prerequisites

Make sure the following are installed:

- Node.js
- npm or pnpm
- Git

### Clone the Repository

```bash
git clone https://github.com/codebyrifaf/antbryx-website.git
```

Navigate to the project:

```bash
cd antbryx-website
```

### Install Dependencies

Using npm:

```bash
npm install
```

Or using pnpm:

```bash
pnpm install
```

---

## Development

Start the development server:

```bash
npm run dev
```

Or:

```bash
pnpm dev
```

The application will normally be available at:

```text
http://localhost:3000
```

---

## Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```
